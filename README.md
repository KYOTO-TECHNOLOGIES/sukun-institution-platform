# Sukun Institution Platform

Institution administration and learning management, built with Django REST Framework and React.

- `institution_management_application/sukun_lms`: API, data models, migrations and backend tests.
- `sukun_lms_frontend`: institution workspace, based on the existing React template.
- The local `queue_management_system_frontend` is a separate reference project and is not part of this repository.

Development work and verification are recorded in `docs/PROGRESS.md`.

Local environment files, databases, uploaded media, dependencies and build output are intentionally excluded from Git. The original nested Git metadata is preserved locally under `.git/legacy-repositories`.
